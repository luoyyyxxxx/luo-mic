========================================
 luo mic —— 让 CS 把手机当麦克风（已配置好）
========================================

结论：全部配好了，直接能用。

------------------------------------------------------------
【你现在只需要 3 步】
------------------------------------------------------------

1. 电脑端：双击 F:\luo-mic\luo-mic-1.0.0-win64.exe
   → 窗口出来后点「启动服务」，状态变成「等待手机连接…」
   → 「播放到」保持「系统默认播放设备」即可（已指向 CABLE Input）

2. 手机端：打开 luo mic，点「开始」

3. 打开 CS：
   设置 → 音频设置 → 麦克风/语音 → 选
       CABLE Output (VB-Audio Virtual Cable)
   如果列表里没有，先点「检测音频设备」，或者干脆不用选 ——
   它已经是 Windows 的默认录音设备，CS 会自动用它。

完事。对着手机说话，CS 里就有声音。

------------------------------------------------------------
【已经做好的配置】
------------------------------------------------------------

1. 安装了 VB-CABLE 虚拟声卡（VB-Audio 官方原版驱动）
   驱动包已放在 U 盘 windows\tools\ 下，以后换电脑可直接复用：
     VBCABLE_Setup_x64.exe      安装器
     VBCABLE_ControlPanel.exe   控制面板
     install-vbcable.bat        一键安装（管理员）

2. 设好了两个默认设备
     播放默认 = CABLE Input    ← luo mic 的声音往这里送
     录音默认 = CABLE Output   ← CS / 微信 / QQ 从这里当麦克风读

   这样任何软件（包括 CS）不用配置就能看到"麦克风"。

------------------------------------------------------------
【实测验证（不是推测）】
------------------------------------------------------------

链路：luo mic 服务端 -> CABLE Input -> CABLE Output -> 录音

  假手机推流       200 帧 / 50.0 帧每秒
  luo mic 连接     成功
  静音时电平       -96.7 dB
  推流时电平       -13.1 dB      ← 有真实信号
  峰值             0.3662         ← 满量程 1.0
  结论             通过

也就是说：从"系统默认录音设备"（CS 读的就是它）确实收到了
手机过来的声音。

------------------------------------------------------------
【想换回原来的麦克风】
------------------------------------------------------------

你的原默认录音设备是「麦克风 (WO Mic Device)」。想切回去：

  powershell -ExecutionPolicy Bypass -File windows\tools\set-default-audio.ps1 -Capture "WO Mic"

或者用界面：设置 → 系统 → 声音 → 输入 → 选回你要的设备。

查看当前状态：
  powershell -ExecutionPolicy Bypass -File windows\tools\set-default-audio.ps1 -List

------------------------------------------------------------
【为什么必须要虚拟声卡】
------------------------------------------------------------

Windows 只允许"内核级驱动"注册麦克风设备。
WO Mic 开箱即用是因为它自带驱动；
luo mic 不自带驱动，所以用免费的 VB-CABLE 中转 ——
手机声音 -> CABLE Input -> CABLE Output -> 软件当成麦克风。

这是 Windows 的限制，不是程序缺陷。

------------------------------------------------------------
【注意】
------------------------------------------------------------

· 录音默认改成 CABLE Output 后，所有"用默认麦克风"的软件都会
  听到手机声音（微信/QQ/Discord/游戏）。这正是你想要的，
  但如果你某个软件要用真实麦克风，就在那个软件里单独选。

· 只在 luo mic 正在运行时才有声音。没开 luo mic 时，
  CABLE Output 是静音的（这是正常的）。

· 没有安装 luo mic 的电脑上用不了 —— 记得带上 U 盘里的
  VBCABLE_Setup_x64.exe 和 luo-mic exe。
