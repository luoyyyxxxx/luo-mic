========================================
 让手机变成电脑麦克风（WO Mic 那种效果）
========================================

先说清楚原理，你就知道为什么必须做下面这几步：

  Windows 只允许「内核级驱动」注册麦克风设备。
  WO Mic 打开就能用，是因为它自带一个驱动。
  luo mic 用的是免费的 VB-CABLE 驱动 —— 效果完全一样：
  装完之后，微信/QQ/Discord/游戏里的「麦克风」列表里会多出一个
  CABLE Output，选中它，对方听到的就是你手机麦克风的声音。


三步搞定（只需做一次，大约 5 分钟）
----------------------------------------

【第 1 步】安装虚拟声卡（luo mic 会自动帮你下载）
   1. 运行 luo mic（双击 windows\build\luo-mic.jar）
   2. 点左下角「安装虚拟声卡」
   3. 弹窗问你要不要自动下载，点「是」
      → 程序会从 vb-audio.com 官网下载驱动包（约 1MB）并静默安装
      → 中途会弹 UAC（蓝色的"你要允许此应用..."），点「是」
   4. 装完【重启电脑】（驱动必须重启才生效）

   如果自动下载失败（网络问题）：
     手动到 https://vb-audio.com/Cable/ 下载
     解压后把 VBCABLE_Setup_x64.exe 放到 windows\tools\ 目录
     再点一次「安装虚拟声卡」按钮即可。

【第 2 步】让 luo mic 把声音送进虚拟声卡
   重启后打开 luo mic：
     · 「播放到」下拉框 → 选 CABLE Input (VB-Audio Virtual Cable)
     · 点「启动服务」
     · 手机打开 luo mic → 点「开始」

   这时电脑端会显示"已连接，正在传输"。

【第 3 步】在你要用的软件里选麦克风
   微信 / QQ：   设置 → 语音视频 → 麦克风 → CABLE Output (VB-Audio Virtual Cable)
   Discord：     用户设置 → 语音和视频 → 输入设备 → CABLE Output
   OBS：         麦克风/辅助音频 → CABLE Output
   游戏内语音：   音频设置里的输入设备 → CABLE Output

   选完就可以说话了 —— 对方听到的是你手机麦克风的声音。


常见问题
----------------------------------------
Q：麦克风列表里找不到 CABLE Output？
   A：① 装完驱动重启了吗？② Windows 设置 → 隐私 → 麦克风 → 允许应用访问
      ③ 有些软件要重启才会刷新设备列表（微信要完全退出再打开）

Q：对方听到的声音很小 / 没声音？
   A：① 手机上 luo mic 界面的电平条有在跳吗？不跳说明手机没采到音
      ② 电脑端 luo mic 的「播放到」选的是 CABLE Input 吗？
      ③ 目标软件的麦克风音量是否拉到 0

Q：我自己也想听到声音（监听）？
   A：Windows 声音设置 → 更多声音设置 → 录制 → CABLE Output → 属性
      → 侦听 → 勾选"侦听此设备" → 选择你的耳机/音箱

Q：不想装驱动行不行？
   A：可以，但只能是"扩音器"效果：
      「播放到」直接选扬声器/耳机，手机声音从电脑音箱放出来。
      这种方式任何软件都拿不到麦克风输入（Windows 的限制）。

Q：能像 WO Mic 那样用蓝牙/USB 线连吗？
   A：目前只支持局域网（Wi-Fi）。局域网方式延迟最低、音质最好，
      实测端到端十几毫秒，比蓝牙稳定得多。
